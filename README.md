OTT Content Analytics Dashboard

Project Overview

This project analyzes OTT platform content using SQL, MySQL, Excel, and Power BI. The objective was to explore content trends, audience ratings, genre performance, and talent insights to uncover meaningful business insights from the dataset.

The project follows an end-to-end analytics workflow, including data cleaning, exploratory data analysis (EDA), business analysis, and interactive dashboard development.

---

Tools & Technologies

* MySQL
* SQL
* Microsoft Power BI
* Microsoft Excel

---

 Project Workflow

1. Imported raw CSV datasets into MySQL.
2. Performed data cleaning and validation.
3. Conducted Exploratory Data Analysis (EDA).
4. Executed business-focused SQL analysis.
5. Exported cleaned datasets.
6. Built an interactive Power BI dashboard.
7. Generated insights through data storytelling and visualization.

---

Dataset

The project uses two datasets:

Titles Dataset

Contains information about OTT content such as:

* Title
* Type (Movie/Show)
* Release Year
* Genres
* Runtime
* IMDb Rating
* Popularity Metrics

Credits Dataset

Contains information about:

* Actors
* Directors
* Roles
* Content Associations

---

Dashboard Pages

1. Executive Overview

Key Metrics:

* Total Titles
* Average IMDb Rating
* Movies vs Shows Distribution
* Content Release Trends
* Top Genres

Business Questions:

* How many titles are available on the platform?
* What type of content dominates the library?
* Which genres are most common?
* How has content production evolved over time?

---

2. Ratings & Genre Analysis

Key Metrics:

* Highest Rated Genres
* IMDb Rating Distribution
* Popularity vs Ratings Analysis
* Top Rated Content

Business Questions:

* Which genres receive the highest ratings?
* How are ratings distributed across the platform?
* Does popularity correlate with ratings?
* Which titles perform best?

---

3. Actor & Director Insights

Key Metrics:

* Most Featured Actors
* Top Rated Directors
* Director Productivity vs Quality
* Talent Role Distribution

Business Questions:

* Which actors appear most frequently?
* Which directors consistently deliver highly rated content?
* Does producing more content lead to better ratings?
* What is the distribution of actors and directors?

---

Key Insights

* Movies represent the majority of available content.
* Content production has increased significantly over time.
* Drama and Comedy are among the most common genres.
* Certain genres consistently achieve stronger audience ratings.
* Popularity does not always translate into higher ratings.
* A small group of actors dominates content appearances.
* Highly productive directors do not necessarily achieve the highest ratings.
* Several directors consistently maintain strong audience reception.
